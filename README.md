## 🚀 Cómo Desplegar en GitHub Pages

1. Sube los archivos a un repositorio en GitHub:
   ```bash
   git init
   git add .
   git commit -m "feat: Invitacion de Boda Julieta & Romeo"
   git branch -M main
   git remote add origin https://github.com/TU_USUARIO/TU_REPOSITORIO.git
   git push -u origin main
   ```
2. En tu repositorio de GitHub, ve a **Settings** > **Pages**.
3. En **Branch**, selecciona `main` y la carpeta `/ (root)`.
4. Haz clic en **Save**. En 1 minuto tendrás tu enlace público listo para compartir con tus invitados.
